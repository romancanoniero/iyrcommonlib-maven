IYR Common Library

Repositorio Maven para Android e iOS. Descarga pública sin token.

Configurar el repositorio

En dependencyResolutionManagement.repositories de settings.gradle.kts:

maven {
    url = uri("https://romancanoniero.github.io/iyrcommonlib-maven")
    content { includeGroup("io.github.romancanoniero") }
}

Agregar la dependencia

En las dependencias de commonMain:

implementation("io.github.romancanoniero:iyrcommonlib:0.1.2")

Android API 23+, iOS 14+, iPhone/iPad ARM64 y simuladores ARM64/x64. Gradle selecciona el paquete de cada plataforma automáticamente.

Modelos, utilidades y detección de plataforma desde commonMain: Platform.current, Platform.isAndroid y Platform.isIOS.

Manifiesto y SHA-256 de 0.1.2 · Clave pública PGP · Licencia MIT · Repositorio de paquetes

La versión está disponible cuando su manifiesto y sus paquetes están publicados. Las versiones anteriores se conservan. El código Android histórico no forma parte del paquete KMP y el repositorio fuente original permanece privado.

Este repositorio Maven se aloja en GitHub Pages y es independiente de Maven Central.
